# Block 02 – Code Smells diagnostizieren

## Lernziel und Abgrenzung

Doppelte Berechnung, globaler Zustand, redundante Anweisung und lange Funktion erkennen. Die clean-Variante entfernt absichtlich nur offensichtlichen Ballast; größere Reparaturen folgen erst später.

## Programmbeispiel

Vergleichen Sie `dirty/02 - Code Smells erkennen und beurteilen/` und `clean/02 - Code Smells erkennen und beurteilen/`. Beide Programme sollen dieselbe fachliche Ausgabe erzeugen.

## Aufgabe

Markieren Sie Smells und bewerten Sie Auswirkung und Priorität. Vergleichen Sie die Ausgabe von dirty und clean. Warum ist ein Smell nicht automatisch ein Bug?

## Reflexion

Welche Verbesserung gehört genau in diesen Block? Welche anderen Verbesserungen würden einen späteren Lernschwerpunkt vorwegnehmen?
